# 对话决策辅助能力修复 Plan

状态：用户明确批准“执行”，2026-09-05 实施及验证完成。依据同目录 conversation-decision-assistance Research。按 AGENTS.md 核心流程大改动要求，批准前不修改产品代码。

## 目标与成功标准

用户每次补充信息后，系统能说明“理解了什么、比较如何改变、当前倾向及代价、还缺哪个关键信息”。回答用户的为什么/如果/帮我选，不只复述所有候选，也不凭空制造确定性结论。

Demo 和普通决策共用能力；演示仅影响数据来源。固定原例与后续条件都进入事实校验；已有饮食行为、预算硬筛选、用户排除、事务与历史恢复保持兼容。

## 设计与关键流程

1. **有上下文的每轮理解**：复用 provider，每轮有语义需求时传入本轮文本、近期对话、已确认条件、上一轮追问、候选 ID/名称/描述/来源。确定性命令/面板编辑继续直接执行；不能因为正则提取了一个预算或偏好就跳过同轮其他语义。
2. **分离表达意图与状态更新**：结构化输出 update/compare/explain/what_if/clarify，及字段 patch、候选补充/纠正、用户关切、最多一个必要问题。模型不得直接写整个 DecisionState。所有候选 ID、字段、数值、证据引用经服务端校验；明确用户新表达优先，模糊推断待确认。假设性“如果”不修改已确认条件。
3. **保留用户补充的事实**：如“B 公司每天通勤两小时”附到 B，带本轮来源；“我不太能接受”记为用户关切，不捏造成任意硬阈值。简称或“它”有唯一依据才解析，不确定则点名追问。候选介绍中的优点不自动转成用户偏好。
4. **基于事实进行取舍分析**：排序仍由现有有效数值和约束产生；解释阶段结合本轮意图输出当前倾向、支持理由、代价、结论改变的原因、关键未知项。没有分数时允许有条件的文字倾向，但需要候选事实支持；不编造分数、薪资、真实稳定性或承诺。只引用存在且未被排除的候选。
5. **可验证的解释契约**：理由携带 candidateId 和已有事实/来源引用；引用不存在、违反硬限制、候选已排除或结论不一致时拒绝该建议并给出明确降级。自由文本本身不能被当成已核验事实；用户与演示数据来源保留。
6. **无模型也推进有限决策**：基于已有数值比较说明具体差异；对文字描述的明确、有限可识别维度给出有条件取舍和一个有区分度的问题。遇到能力范围外的自由表达，说明尚未形成哪项理解并请求具体补充，禁止把未处理输入伪装成已分析。界面区分规则体验/模型辅助，不能承诺任意对话等效真实模型。
7. **同步侧栏和历史**：侧栏展示倾向、依据、代价、关键未知；本轮变化可见，保存到当前 revision 的快照。无需重复粘贴完整候选说明。新增中间状态放现有 domainState，不新建表。

模型使用现有 light/main 配置：理解最多一次、解释最多一次；确定性可直接完成的操作不额外调用。提供有限上下文和候选数量，明确错误/超时降级，不无限重试。

## 兼容、风险和取舍

- 不改变 API 地址、依赖、存储表和运行环境；新状态字段有旧记录默认值，不迁移旧 Demo 的评分/约束。
- 不以“更聪明”为由解除已确认条件/清空保护。模型猜测和用户明确纠正走不同校验分支。
- 来源引用合法不等同于自然语言蕴含必然正确；用结构化依据、拒绝明显矛盾、人工审阅金样例及真实模型验收共同约束，不宣称能完全消除幻觉。
- 规则体验能力明确有限，重点证明其能处理规定的四类示例与改动，不继续靠增加任意关键词冒充通用推理。
- 网络失败保留原条件及草稿，返回实际模式/原因，已有请求重试不重复提交业务变更。

## 验证

- 基线：重跑现有 98 项测试并保存工作区快照；检查本次 diff，不混入此前改动。
- Offer 三轮金样例：更看重稳定 → 基于示例说明 B 的条件性优势和岗位方向代价；为什么不选 A → 正面解释 A 的优势与当前优先级关系；B 通勤两小时难以接受 → 更新 B 信息与关切、说明取舍变化，不能重复旧结论。
- 学习：“零编程基础、每周三小时”被记录并影响路径建议；随后补充“已有 Python 基础”能纠正，不重复问已回答内容。
- 购物：“预算不变，但更看重续航，为什么选它”同时处理偏好与解释；任何倾向仍满足预算/排除条件。
- 旅行：预算收紧、交通时长和假设雨天分别处理；不能宣称示例已适配真实出发路线或天气。
- 无模型、模型正常 mock、无效 schema/不存在候选/矛盾来源/超时、重试/409/刷新、旧清空值不复活均覆盖。
- 浏览器对话验收必须检查回复内容与依据变化，不能只断言按钮可点、HTTP 200 或消息变多。
- 全量 pytest、compileall、JS syntax、diff 检查。真实外部模型有可用授权配置才验证，缺凭据明确记录，mock 不算真实模型验收。
