## 使用说明

无需安装依赖，直接打开 `index.html` 查看 Choice Agent 产品展示方案。

## 内容说明

迁移自 `tx` 文件夹的产品方案网站结构，并改造成 Choice Agent 版本，包含四部分：

1. 产品定位：定义 Choice Agent 与普通聊天 AI、推荐系统的边界。
2. 处理方式：说明从模糊选择到可解释决策的端到端链路。
3. 可交互 demo：用 Offer、旅行和购物三个典型 case 展示决策过程。
4. 体验衡量：定义可采纳率、解释质量、证据质量、Bad Case 归因和看板分层。

## Demo 说明

页面内数据均为静态模拟数据，用于展示产品思路、作品集汇报和交互叙事，不代表真实 API 运行结果。
